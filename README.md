# Ultimate Chess

## 项目简介

Ultimate Chess 是一款由九个井字棋小盘组成的双人棋类游戏, 提供命令行人机对弈. 对弈 AI 使用 PyTorch 策略-价值网络和蒙特卡洛树搜索进行推理, 可以从随机权重开始自博弈训练.

## 规则介绍

大盘由九张 `3×3` 小盘组成. 小盘编号和每张小盘内部的格号都按同样的顺序排列. 

```text
1 2 3
4 5 6
7 8 9
```

1. **首手与送盘:** X 先手, 第一步必须下在中央的 5 号小盘. 此后双方轮流落子, 每一步的格号决定对手下一步的小盘编号. 例如 X 在 5 号盘的 3 号格落子, O 下一步就去 3 号盘. 
2. **自由选盘:** 如果指定小盘已经分出胜负或填满, 可以任选一张仍开放的小盘, 在其中的空格落子. 
3. **小盘胜负:** 同一方在小盘内连成一行、一列或一条对角线, 就赢下该盘, 小盘随即关闭. 填满但双方都没有三连时, 小盘记和. 即使小盘所有连线都被堵住, 只要它还有空格且没有三连, 就继续开放. 
4. **整局胜负:** 赢下大盘同一行、列或对角线上的三个小盘, 就赢得整局. 对任一方, 只要一条线上含有对手已赢的小盘或和棋小盘, 这条线就已堵死. 双方在大盘上的八条线都被堵死时立即判和, 即使仍有小盘可以落子. 

## 神经网络架构

ChessNet 从当前行棋方视角编码棋局. 每个小盘有三张 `3×3` 输入特征图, 分别标记己方棋子、对方棋子和合法落点. 每盘另有五个状态特征, 表示进行中、己方已赢、对方已赢、和棋, 以及本回合能否在该盘落子. 

| 模块 | 结构与输出 |
| --- | --- |
| 小盘编码器 | 九张小盘共用一个 32 通道卷积层和两个残差块. 保留每格的 32 维特征, 再将每盘九格的特征与五个状态特征拼接, 投影成 64 维小盘向量.  |
| 大盘编码器 | 将九个小盘向量按盘位排成 `64×3×3` 特征图, 再经过两个 64 通道残差块, 得到包含大盘上下文的小盘特征.  |
| 策略头 | 拼接落子格、来源盘和目标盘的特征, 经 `160 → 64 → 1` 的共享网络为每个动作打分. 81 个动作中, 只有合法动作参与 softmax.  |
| 价值头 | 展开大盘特征, 经 `576 → 128 → 3` 网络预测当前行棋方的胜、和、负概率. 搜索使用 `P(胜) − P(负)` 作为局面估值.  |

给一个动作打分时, 策略头会同时考虑来源盘和目标盘. 例如在 2 号盘的 7 号格落子, 网络既能看到 2 号盘的局部形势, 也能看到对手将前往的 7 号盘. 如果 7 号盘已关闭, 搜索会按照自由选盘规则生成对手的应手. 

## 训练方法

### 配置环境



### 运行自博弈

```shell
python -m ultimate_chess.training
```

训练参数见 [training.py](ultimate_chess/training.py), 默认每次运行 10 轮, 每轮结束保存一次. 检查点 `runs/latest.pt` 已存在时会自动续训. 

## 试玩方法

准备好训练检查点后, 在项目根目录运行:

```shell
python -m ultimate_chess
```

默认加载 `runs/latest.pt`. 使用其他模型时, 把检查点路径放在命令末尾, 例如: 

```shell
python -m ultimate_chess runs/example.pt
```

- 开局输入 `X` 执先手, 输入 `O` 执后手, 直接回车默认执 X. 
- 每回合输入 **小盘编号和格号**, 用空格隔开. 例如 `5 3` 表示在 5 号盘的 3 号格落子. 终端会提示当前指定小盘. 输入 `q` 退出.
- 小盘标题中的 `.` 表示仍在进行, `X` 或 `O` 表示该方已赢, `=` 表示和棋.  
- AI 每手运行 64 次 MCTS, 选择访问次数最多的动作.
